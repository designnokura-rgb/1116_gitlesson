Git hubの手順

  1. ターミナルからbashを選択
  2. Git/GitHubでは、「リポジトリ」という場所をつくり、そこにファイルやフォルダを保管してバージョン管理をします。
  3. git init：今いるフォルダ（ディレクトリ）をGitの管理下（ローカルリポジトリ）にするためのコマンド
  4. ローカルリポジトリ：自分のPC上に作るリポジトリ
  5. リモートリポジトリ：クラウド上に作るリポジトリ
  6. ブランチ：リポジトリをコピーして分岐させる機能
  7. 分岐させたブランチは、他からの影響を受けないため、複数機能の開発などを、他のメンバーの影響を受けずに並行して行える
